备份任务运行过，不等于数据真的可恢复。真正危险的，是那些直到恢复当天才暴露的路径漂移、过期快照和遗漏卷。

Restorix 把当前 Mac 上的 Docker volumes，与真实 restic snapshots 逐一比对。它检查路径、主机名和时间阈值，把模糊的“应该备份了”，变成可以解释的状态。

在仪表盘里，已保护、未保护、已过期、未知和错误一目了然。Docker、restic、容器和 volumes 的环境状态，也会同时给出。

Restorix 不执行备份，也不替代 restic。它是一层独立的验证工具，只回答一个关键问题：这些 Docker 数据，最近是否被足够新的快照覆盖。

你可以添加多个 restic 仓库，指定预期快照主机名，并在本机测试仓库连接。密码仍然由环境变量和 macOS 钥匙串管理。

扫描结果可以生成 Markdown 健康报告，方便审计、事故记录和团队交接。复制、保存，再把风险和下一步动作交给真正需要处理的人。

应用支持简体中文、菜单栏快速查看、可调的过期阈值，以及多套图标。底层 Rust Core 与 macOS 界面使用同一套健康模型。

在真正恢复之前，先知道风险在哪里。Restorix，让 Docker volume 的备份状态有证据、可解释、可行动。
